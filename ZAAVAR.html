1. Суулгах

  1. Helmerch-Setup-….exe-ийг давхар товшино.
    "Windows protected your PC" гэж гарвал → More info → Run anyway.
  2. Цааш → Цааш → Суулгах. 1–2 минут болно.
    • NVIDIA видео карттай бол "Видео картын хурдан горим" өөрөө сонгогдоно (~1.5 GB интернэтээс татна).
    • Gemini түлхүүр асууна (доорх Түлхүүр хэсгийг харна уу). Алгасаж ч болно.
  3. Сүүлийн алхамд Chrome өргөтгөлийг нэг удаа нэмнэ (доорх 2-р хэсэг).
  4. Дууссаны дараа Desktop болон Start цэсэнд товчлол гарч, цагны хажууд дүрс харагдана.
Компьютер асах бүрт програм өөрөө чимээгүй асна. Устгахдаа Windows-ийн Settings → Apps-аас устгана.

2. Chrome өргөтгөл суулгах (нэг удаа)

Суулгагч Chrome-ийн өргөтгөлийн хуудсыг нээж, хавтасны хаягийг хуулчихсан байна.

  1. Баруун дээд буланд Developer mode-ийг асаана.
  2. Load unpacked товч дарна.
  3. Хавтас сонгох цонхны дээд хаягийн мөрөнд Ctrl+V дараад Enter, дараа нь Select Folder.
  4. Хэлмэрч өргөтгөл дээр Details → Allow access to file URLs-ийг асаана (компьютер дээрх PDF-д хэрэгтэй).
  5. Chrome-ийн баруун дээд талын 🧩 дүрс → Хэлмэрч-ийн хажуугийн 📌 дарж тогтооно.
Өргөтгөл шинэчлэгдсэн гэж хэлвэл chrome://extensions хуудсанд Хэлмэрч дээрх ↻ товчийг дарж, нээлттэй хуудсуудаа refresh хийнэ.

3. Видео хадмал

  1. Chrome дээр YouTube эсвэл кино сайтаас видеогоо тоглуулна.
  2. Видео бүр хадмал унтраалттай эхэлнэ. Зүүн дээд буланд МН · хадмал асаах гарна — дээр нь дарна (эсвэл Alt+M).
  3. МН · бэлтгэж байна… → хэдэн секундийн дараа МН ✓ болж хадмал гарна. Дахин дарвал унтарна.
  4. Видео англи хадмалтай бол Хэлмэрч түүнийг нь шууд ашиглана (илүү хурдан, нарийн). Netflix гэх мэт сайтад видеон дээрх англи хадмалыг асааж өгвөл дэлгэц дээр гарсан мөр бүрийг шууд монгол болгож дээр нь харуулна — МН ✓ (дэлгэцийн хадмалаас).

4. PDF орчуулах (хичээл үзэхэд)

  1. PDF файлаа Chrome-оор нээнэ (файл дээр баруун товч → Open with → Google Chrome, эсвэл Chrome руу чирж оруулна).
  2. PDF автоматаар Хэлмэрч үзүүлэгчээр нээгдэж, хуудас бүрийн хажууд яг ижил загвартай монгол хуудас гарна — хүснэгт, жагсаалт, гарчиг, тод үсэг, өнгө хэвээрээ.
  3. Монгол хуудсан дээрх үг дээр хулгана аваачихад англи эх нь гарна.
  4. Эхлээд хурдан AI-аар (1–2 секунд) орчуулга гараад, дараа нь хүчтэй AI-ийн мэргэжлийн орчуулгаар солигдоно (✨). Google орчуулга зөвхөн AI ажиллахгүй үед нөөц болно.

5. Үг, текст орчуулах

Үг дээр

Ctrl товчийг дарсан чигтээ хулганаа үг дээр аваачихад тухайн үгийн орчуулга болон бусад утгууд гарна. (Тохиргооноос "Шууд" болговол Ctrl дарах шаардлагагүй.)

Текст сонгоход

Өгүүлбэр, догол мөрийг хулганаар сонгоход хажууд нь орчуулга гарна. Хуулах товчоор орчуулгыг хуулна. Esc эсвэл өөр газар дарж хаана.

6. Вэб хуудсыг орчуулах

  1. Chrome-ийн баруун дээд талын Хэлмэрч дүрс дээр дарахад цэс нээгдэнэ.
  2. Вэб хуудсыг орчуулах хэсгээс сонгоно: Эх — хуудас өөрчлөгдөхгүй (анхдагч) · 2 хэл — догол мөр бүрийн доор монгол орчуулга · Монгол — хуудасны текст монголоор солигдоно.
  3. Сонголт бүх хуудсанд хадгалагдана — дахин Эх сонгох хүртэл өөрчлөгдөхгүй.
  4. 2 хэл горимд цэс, товчны доор жижиг үсгээр орчуулга гарна (цэсний «Цэс, товчийг ч орчуулах»-ыг унтраавал хулгана аваачихад л гарна). Үндсэн агуулга (өгүүлэл, гарчиг, догол мөр) орчуулагдана — цэс, товч, хөлийн хэсэг эх хэлээрээ үлдэж хуудас бөөгнөрөхгүй. Монгол горимд бүгд орчуулагдана.
  5. Орчуулгын хэлбэр (2 хэл үед): Зураас · Дэвсгэр · Цээжлэх — орчуулга бүдэг харагдаж, хулгана аваачихад тодорно. Эхлээд өөрөө ойлгохыг оролдоод дараа нь шалгахад тохиромжтой.
  6. Монгол горимд орчуулга дээр хулгана аваачихад эх англи текст нь гарна.
  7. Тодорхой сайтыг орчуулахгүй байлгах: цэсний «… хэзээ ч бүү орчуул» тэмдэглэгээ, эсвэл хуудасны буланд гарах товчны × → сайтыг хасах.
  8. Орчуулж байх үед хуудасны буланд жижиг Эх / 2 хэл / Монгол товч гарна. Сайтын товч (жишээ нь шалгалтын Next) доор нь байвал өөр булан руу өөрөө шилжинэ.
  9. 📝 Шалгалтын горим (цэсэнд): асуулт, хариултын бүх сонголт (товч хэлбэртэй ч), хариулсны дараа гарах тайлбарыг бүрэн орчуулна. Шалгалтын болон сургалтын сайтад асаана.
  10. Хуудсан дотор шигтгэсэн цонх (сургалтын сайтууд) байвал түүн доторх текст ч орчуулагдана.
  11. Баруун товчны цэснээс ч болно: Хэлмэрч: хуудсыг орчуулах, Хэлмэрч: сонгосон текстийг орчуулах.
  12. Хуучин хажуу самбар: цэсний доод талын Хажуу самбарт нээх.

7. Дэлгэцээс орчуулах

  1. Ctrl+Alt+T дарна (эсвэл програмын цонхны том товч).
  2. Дэлгэц бүдгэрнэ — орчуулах хэсгээ хулганаар зурна. Esc = болих.
  3. 5–20 секундийн дараа монгол орчуулга болон эх текст гарна.

Зураг, скан PDF, Word, PowerPoint, тоглоом — дэлгэц дээр харагдаж байгаа бүх зүйл дээр ажиллана. Gemini түлхүүр хэрэгтэй.

8. Түлхүүр (заавал биш, гэхдээ орчуулга маш их сайжирна)

Програмын цонхны ▶ Түлхүүр авах заавар, ▶ Токен авах заавар товч дээр дарахад алхам бүрийг хөдөлгөөнтэйгээр харуулдаг заавар нээгдэнэ.

Gemini түлхүүр (үнэгүй)

  1. aistudio.google.com/apikey хаягаар Google акаунтаараа орно.
  2. Create API key дарж түлхүүрээ хуулна.
  3. Програмын цонх → Gemini түлхүүр → буулгаад Хадгалах.

Copilot токен (GitHub, үнэгүй)

  1. Програмын цонх → ▶ Токен авах заавар → GitHub-ийг нээх → GitHub-д нэвтэрнэ.
  2. Token name: Хэлмэрч · Expiration: хүссэн хугацаа.
  3. Permissions → Models → Read-only болгоно (заавал!).
  4. Generate token → токеноо хуулна → програмд Copilot токен → Хадгалах → Шалгах.

9. Тохиргоо

Цагны хажууд байгаа Хэлмэрч дүрс дээр дарахад Хэлмэрч-ийн цонх нээгдэнэ (эсвэл Desktop дээрх Хэлмэрч товчлол). Бүх тохиргоо асаах/унтраах товчоор шууд хадгалагдана. (Дүрс харагдахгүй бол цагны хажуугийн ˄ сумыг дарна.)

Орчуулсан текстүүд компьютер дээр хадгалагддаг тул дахин нээхэд шууд гарч, AI-ийн үнэгүй хязгаар хэмнэгдэнэ.

Дүрс дээр баруун товч: Нээх · Дэлгэцээс орчуулах · Видео хадмал асаах/унтраах · Текст орчуулга асаах/унтраах · Дахин эхлүүлэх · Гарах.

Дүрсний хээний өнгө: улаан = бэлэн · улбар шар = загвар ачаалж байна · саарал = алдаа.

Шинэ хувилбар суулгах

  1. Шинэ хувилбар гармагц програмын цонхны дээд талд «Шинэ хувилбар … гарлаа — Шинэчлэх» гарна. Дарахад өөрөө татаж суулгагчийг нээнэ. (Эсвэл шинэ Setup.exe-г гараар ажиллуулна.) Тохиргоо, түлхүүр, үгс хадгалагдана.
  2. Нээгдэх chrome://extensions хуудсанд Хэлмэрч дээрх ↻ товчийг дарна.
  3. Хувилбарыг Хэлмэрч цонхны гарчиг эсвэл PDF үзүүлэгчийн дээд мөрөөс (жишээ нь v1.5.1) шалгана.

Устгах

Windows-ийн Settings → Apps (эсвэл Control Panel → Programs) → Хэлмэрч → Uninstall. Дараа нь chrome://extensions дээр Хэлмэрч → Remove.
