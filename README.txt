ХЭЛМЭРЧ
==========
Дэлгэрэнгүй, зурагтай заавар: ZAAVAR.html файлыг нээнэ үү.
Видеог монгол хадмалтай үзэх, PDF болон вэб хуудсыг монгол руу орчуулах програм.

СУУЛГАХ
1. Helmerch-Setup-….exe-г давхар товшино.
   "Windows protected your PC" гэвэл → More info → Run anyway.
2. Цааш → Цааш → Суулгах (1–2 минут). Сүүлийн алхамд Chrome өргөтгөлийг нэг удаа нэмнэ.

ХЭРЭГЛЭХ
• Видео: видеоны зүүн дээд булан дахь «МН» товч (эсвэл Alt+M) дарж монгол хадмал асаана.
• PDF: PDF-ээ Chrome-оор нээхэд хуудас бүрийн хажууд орчуулга гарна.
• Үг: Ctrl дараад хулганаа үг дээр аваачна.
• Текст: хулганаар сонгоход орчуулга гарна.
• Хуудас: Chrome-ийн баруун дээд талын Хэлмэрч дүрс → Эх / 2 хэл / Монгол.
• Дэлгэц: Ctrl+Alt+T → орчуулах хэсгээ зурна (зураг, скан PDF, ямар ч програм).
• Тохиргоо: цагны хажууд байгаа Хэлмэрч дүрс дээр дарна.

ШИНЭ ХУВИЛБАР
Шинэ Setup.exe-г ажиллуулна (тохиргоо, түлхүүр хадгалагдана),
дараа нь chrome://extensions → Хэлмэрч → ↻ дарна.

УСТГАХ
Windows Settings → Apps → Хэлмэрч → Uninstall.
